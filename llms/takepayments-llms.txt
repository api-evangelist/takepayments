# takepayments

> takepayments (a trading name of Payzone UK Limited) is a UK payment gateway and merchant-services provider for accepting card payments online, in person, and over the phone. It offers a legacy online payment Gateway API (Hosted redirect + Direct server-to-server, SOAP v1.1 XML / HTTPS form-POST, merchant-ID + pre-shared-key signature auth) and a modern REST/JSON Terminal API on Azure API Management (OAuth 2.0 client-credentials via Microsoft Azure AD) that pairs and drives card machines (Move5000, PAX A920 Pro). No downloadable OpenAPI is published; the reference is documentation-only.

## APIs
- [takepayments Gateway API](https://www.takepayments.com/developer-support/): Hosted + Direct online card-payment integrations (SOAP/form-POST).
- [takepayments Terminal API](https://developer.takepayments.com/apis): REST/JSON card-machine control (Start Transaction, Pairing, Split Bill & Gratuity, Pay at Table).

## Authentication
- [Terminal API auth](https://developer.takepayments.com/documentation/authentication): OAuth 2.0 client-credentials, Azure AD. Token: https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token — scope `https://takepaymentsintegratedprod.onmicrosoft.com/{ClientId}/.default` — header `Authorization: Bearer {JWT}`.
- Prod tenant: takepaymentsintegratedprod.onmicrosoft.com; Sandbox tenant: takepaymentsintegrated.onmicrosoft.com.
